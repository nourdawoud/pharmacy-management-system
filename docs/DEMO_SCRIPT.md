# Phase 1 Demo Script
1. Log in as admin, then as employee: show the different permissions.
2. Add, edit and search a medicine.
3. Open inventory: show a low-stock and an expiring medicine.
4. Make a sale, show the invoice, and show the stock decrease.
5. Try to sell an expired medicine: show it is blocked.
6. Record a purchase from a supplier: show the stock increase.
7. Show the dashboard numbers.
8. Open GitHub: issues, project board, branches, PR history, per-member commits.
